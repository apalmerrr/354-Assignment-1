# Programming Assignment 1: Lark Calculator

A command line calculator built in Python with a parser generated by [Lark](https://github.com/lark-parser/lark). It supports `+`, `-`, `*`, `^`, unary minus, `log ... base ...` and parentheses, following the usual order of operations.

**Team:** Alex Palmer

## Files

```
Assignment1/
    calculator_cfg.py   parses, builds the AST and evaluates it
    grammar.lark        unambiguous grammar used to generate the parser
    specs.md            detailed specification, grammar and order of operations
```

## Setup

Requires Python 3 and Lark:

```
pip install lark
```

## Usage

Run from the repo folder and pass the expression in quotes:

```
python Assignment1/calculator_cfg.py "1+2*3"
7
```

More examples:

| Input | Output |
|---|---|
| `2-(4+2)` | -4 |
| `--1` | 1 |
| `2^3^2` | 512 |
| `-3^2` | -9 |
| `log 8 base 2 + 1` | 4 |

## Order of Operations

From tightest to loosest binding:

1. Parentheses
2. `^`, grouped right to left
3. Unary `-` and `log ... base ...`
4. `*`, grouped left to right
5. `+` and `-`, grouped left to right

See [`Assignment1/specs.md`](Assignment1/specs.md) for the full grammar, the reasoning behind these choices, and a description of every method.
